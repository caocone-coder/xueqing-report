# 客户详情页（未授权）产品需求文档

## 基本信息
- 模块名称：客户详情页（未授权）
- 所属产品：学情跟进提醒
- 页面ID：page-customer-unauthorized
- 文档版本：v1.0
- 日期：2026-04-17

---

## 一、模块概述

### 1.1 功能定位
展示未授权客户的基本信息、授权状态、历史跟进记录，引导学管师发起授权申请。

### 1.2 使用场景
- 学管师查看客户基本信息
- 查看历史跟进记录（日/周视图）
- 发起伴学授权申请

### 1.3 用户角色
学管师/督学

---

## 二、页面结构

### 2.1 页面布局
- 顶部导航栏（蓝色，44px）
- 客户信息卡片
- 授权状态卡片
- 日/周切换 Tab
- 时间轴列表（可滚动）

### 2.2 UI 组件清单

| 组件名 | 类型 | 说明 |
|--------|------|------|
| `.nav-bar` | 导航栏 | 蓝色背景，左侧返回按钮，中间标题"客户详情" |
| `.customer-info-card` | 卡片 | 客户头像、姓名、手机号、标签（年级/科目） |
| `.auth-card` | 卡片 | 授权状态"未授权"，"申请授权"按钮 |
| `.tabs` | Tab切换 | "按日"/"按周"切换 |
| `.timeline-entry` | 时间轴条目 | 日期标题 + 跟进记录列表 |

---

## 三、功能需求

### 3.1 核心功能

1. **客户信息展示**
   - 头像：48x48 圆形
   - 姓名：张小美妈妈
   - 手机号：138****1234
   - 标签：年级（小学三年级）、科目（数学、英语）、企微图标

2. **授权状态展示**
   - 状态标签："未授权"（灰色背景）
   - 说明文字："您还未获得查看该客户学习数据的授权"
   - 操作按钮："申请授权"（蓝色按钮）

3. **跟进记录时间轴**
   - 按日/按周切换
   - 日期分组（如"2026年4月17日 周四"）
   - 每条记录包含：
     - 时间戳（如"14:30"）
     - 学员名称（如"张小美"）
     - 跟进内容（如"完成数学作业3题"）
     - 提醒文字（如"建议关注错题订正"）

### 3.2 交互规则

| 交互 | 触发 | 结果 |
|------|------|------|
| 点击"申请授权" | 按钮点击 | 跳转到企微聊天页（page-wechat-chat） |
| 点击"按日"/"按周" | Tab点击 | 切换时间轴视图（当前为mock，无实际数据切换） |
| 点击返回按钮 | 导航栏左侧 | 调用 `parent.goBack()` |

### 3.3 状态说明
- 默认显示"按日"视图
- 授权状态固定为"未授权"

---

## 四、导航与跳转

### 4.1 进入路径
- 应用启动默认页（首页）
- 从其他页面返回

### 4.2 离开路径
- 点击"申请授权" → 企微聊天页（page-wechat-chat）

### 4.3 返回逻辑
- 点击导航栏返回按钮 → `parent.goBack()`

## 五、数据说明

### 5.1 展示数据字段

**客户信息：**
```javascript
{
  avatar: "data:image/svg+xml;base64,...", // 头像
  name: "张小美妈妈",
  phone: "138****1234",
  tags: ["小学三年级", "数学", "英语"],
  hasWechat: true
}
```

**跟进记录：**
```javascript
{
  date: "2026年4月17日 周四",
  entries: [
    {
      time: "14:30",
      student: "张小美",
      content: "完成数学作业3题",
      alert: "建议关注错题订正"
    }
  ]
}
```

### 5.2 数据来源
当前为前端 mock 数据，未来对接后端接口。

## 六、异常与边界

### 6.1 空状态
- 无跟进记录时：显示"暂无跟进记录"

### 6.2 异常处理
- 头像加载失败：显示默认头像
- 手机号脱敏：中间4位显示为 `****`
