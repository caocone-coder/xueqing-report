# 应用足迹·自研应用 产品需求文档

## 基本信息
- 模块名称：应用足迹·自研应用
- 所属产品：学情跟进提醒
- 页面ID：page-footprint-self
- 文档版本：v1.0
- 日期：2026-04-17

---

## 一、模块概述

### 1.1 功能定位
展示学员在自研应用中的详细使用足迹，按日期分组显示课程学习记录和时间轨迹。

### 1.2 使用场景
- 学管师查看学员某个自研应用的详细使用情况
- 查看每日课程完成记录
- 查看每日时间分布

### 1.3 用户角色
学管师/督学

---

## 二、页面结构

### 2.1 页面布局
- 顶部：状态栏 + 导航栏
- 应用头部：应用图标 + 名称 + 总使用时长 + 分享按钮
- 时间轴列表（可滚动）：
  - 日期分组
  - 每日课程详情（可折叠）
  - 每日时间轨迹（可折叠）

### 2.2 UI 组件清单

| 组件名 | 类型 | 说明 |
|--------|------|------|
| `.status-bar` | 状态栏 | 时间、信号、电量 |
| `.nav-bar` | 导航栏 | 返回按钮 + 标题 |
| `.app-header` | 应用头部 | 应用信息 + 分享按钮 |
| `.timeline` | 时间轴 | 日期分组列表 |
| `.date-header` | 日期头部 | 日期 + 总时长 + 展开/收起图标 |
| `.date-content` | 日期内容 | 课程详情 + 时间轨迹 |
| `.course-section` | 课程区块 | 课程列表 |
| `.course-item` | 课程条目 | 课程名称 + 完成状态 + 时长 |
| `.timeline-section` | 时间轨迹区块 | 时间轴图 |

## 三、功能需求

### 3.1 核心功能

#### 1. 应用头部
- 应用图标：45x45，圆角 8px
- 应用名称：瑞恩熊AI英语
- 总使用时长：本周使用 1小时39分钟
- 分享按钮：点击分享（当前无实际功能）

#### 2. 日期分组
- 按日期倒序排列（最新日期在上）
- 每个日期显示：
  - 日期：4月16日 周三
  - 当日总时长：1小时39分钟
  - 展开/收起图标

#### 3. 课程详情（默认展开）
- 标题："课程详情"
- 课程列表：
  - 课程名称（如"Lesson 1: Hello"）
  - 完成状态：已完成（绿色勾选图标）/ 进行中（橙色进度图标）
  - 学习时长：15分钟

#### 4. 时间轨迹（默认展开）
- 标题："时间轨迹"
- 时间轴：
  - 横轴：时间点（08:00 - 20:00）
  - 纵轴：使用时段（蓝色条形图）
  - 悬停/点击显示具体时段和时长

#### 5. 折叠/展开
- 点击日期头部 → 折叠/展开该日期的课程详情和时间轨迹
- 默认状态：全部展开
- 折叠动画：maxHeight 过渡

### 3.2 交互规则

| 交互 | 触发 | 结果 |
|------|------|------|
| 点击返回按钮 | 导航栏左侧 | `parent.goBack()` |
| 点击分享按钮 | 应用头部右侧 | 显示分享面板（当前无实际功能） |
| 点击日期头部 | 日期行点击 | 折叠/展开该日期内容 |

### 3.3 状态说明
- 默认全部日期展开
- 课程完成状态：已完成 / 进行中

## 四、导航与跳转

### 4.1 进入路径

- 导航栏返回按钮 → `parent.goBack()`

## 六、异常与边界

### 6.1 空状态
- 无课程记录：显示"暂无课程记录"
- 无时间轨迹：显示"暂无时间轨迹"

### 6.2 异常处理
- 应用图标加载失败：显示默认图标
- 时间轨迹数据异常：隐藏时间轨迹区块
