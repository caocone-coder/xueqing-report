---

## 一、模块概述

### 1.1 功能定位
定义全局页面切换机制、导航历史管理，以及各页面复用的通用 UI 组件（Toast、Loading Overlay）。

### 1.2 技术架构
采用单 HTML 文件 + 多 iframe 方案：
- 每个页面封装为独立 iframe（srcdoc 内联）
- 父页面统一管理页面显示/隐藏与导航历史
- 子页面通过 `parent.navigateTo()` / `parent.goBack()` 调用父页面导航函数

## 二、全局导航系统

### 2.1 页面切换

| 函数 | 说明 |
|------|------|
| `navigateTo(pageId)` | 显示目标页面，隐藏其他页面，将 pageId 压入历史栈 |
| `goBack()` | 弹出历史栈顶，显示上一页 |
| `refreshIframeLayout(pageId)` | 页面显示后延迟 80ms 重算可折叠区域高度（解决 hidden iframe 中 scrollHeight=0 问题） |

### 2.2 历史栈
- 初始值：`['page-customer-unauthorized']`
- `navigateTo` 压栈，`goBack` 出栈
- 栈长度为 1 时，`goBack` 不执行（防止退出到空页面）

### 2.3 页面 ID 清单

| pageId | 页面名称 |
|--------|---------|
| page-customer-unauthorized | 客户详情（未授权） |
| page-wechat-chat | 企微聊天页 |
| page-auth-request | 伴学授权申请 |
| page-customer-authorized | 客户详情（已授权） |
| page-dashboard | 学情跟进提醒 |
| page-footprint-self | 应用足迹·自研 |
| page-footprint-third | 应用足迹·三方 |
| page-report-detail | 学习计划详情 |
| page-student-report | 学情周报 |

## 三、通用组件

### 3.1 Toast 通知

- 触发方式：调用 `showToast(message)`
- 展示时长：1.5s 后自动消失
- 样式：底部居中浮层，圆角背景，白色文字
- 使用场景：授权成功提示、复制成功提示

### 3.2 Loading Overlay

- 触发方式：显示 `.loading-overlay` 元素
- 样式：全屏半透明遮罩 + 居中 spinner 动画
- 使用场景：客户详情页（已授权）点击"发送给家长"后，模拟发送延迟（3s）

### 3.3 导航栏（Nav Bar）

各页面独立实现，统一规范：
- 高度：44px
- 背景色：`#3478f6`（蓝色）或白色（依页面设计）
- 左侧：返回按钮（`parent.goBack()`）
- 中间：页面标题
- 右侧：可选操作按钮
