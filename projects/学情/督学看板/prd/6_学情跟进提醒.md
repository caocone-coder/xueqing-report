# 学情跟进提醒（督学看板）产品需求文档

## 基本信息
- 模块名称：学情跟进提醒（督学看板）
- 所属产品：学情跟进提醒
- 页面ID：page-dashboard
- 文档版本：v1.0
- 日期：2026-04-17

---

## 一、模块概述

### 1.1 功能定位
学管师工作台核心页面，聚合展示学员学习数据（日历、应用使用、学习计划）、生成督学话术，支持一键复制发送给家长。

### 1.2 使用场景
- 学管师查看学员本月学习日历
- 查看学员应用使用时长排行
- 查看学习计划完成进度
- 根据不同维度（基础使用/学科使用/异常提醒）和场景（表扬鼓励/提醒督促/关怀回访）生成督学话术
- 点击应用进入应用足迹详情
- 点击学习计划进入计划详情
- 点击学情报告卡片进入学情周报

### 1.3 用户角色
学管师/督学

## 二、页面结构

### 2.1 页面布局
- 顶部固定区域：
  - 导航栏（返回按钮 + 标题"学情跟进提醒"）
  - 家长姓名 + 标签（新购机用户、学情深度关注、小程序高活跃）

  - 学习日历卡片
  - 应用使用卡片
  - 学习计划卡片
  - 督学话术卡片

| 组件名 | 类型 | 说明 |
|--------|------|------|
| `.nav-bar` | 导航栏 | 返回按钮 + 标题 |

## 三、功能需求

### 3.1 核心功能

#### 1. 子女切换
- 支持多子女家庭，Tab 切换不同孩子的数据
- 示例：张小明（五年级）、张小美（二年级）
- 切换后所有卡片数据联动更新

#### 2. 学习日历
- 展示当月日历（4月，2026年）
- 已使用日期：蓝色背景
- 未使用日期：灰色背景
- 统计信息：
  - 本月已使用 X 天
  - 连续未使用 X 天（大于0时显示）
- 展开/收起功能（默认收起，点击"展开"显示完整日历）

#### 3. 应用使用
- 日期标签：4月16日
- 总时长：3小时31分钟
- 对比：相比前一天少学1小时29分钟
- 应用列表：
  - 自研应用（5个）：瑞恩熊AI英语、分级阅读、新概念英语、口算练习、语文同步
  - 三方应用（1个）：英语天天练
  - 每个应用显示：图标、名称、时长、进度条
- 点击应用 → 跳转应用足迹页（区分自研/三方）

#### 4. 学习计划
- 计划列表（3个）：
  - 小飞 7 天新手任务（落后，2/7，29%）
  - 小学语文春季同步计划2026年（落后，1/7，14%）
  - 小学英语春季同步计划2026年（落后，0/7，0%）
- 综合完成率：14%（3/21）
- 落后计划数：当前3个计划进度落后
- 点击计划 → 跳转学习计划详情页

#### 5. 督学话术
- 三个维度 Tab：
  - 基础使用（3个场景：表扬鼓励、提醒督促、关怀回访）
  - 学科使用（仅1个场景：表扬鼓励，显示学情报告卡片）
  - 异常提醒（2个场景：异常时间、异常内容，红色角标"2"）
- 场景切换：点击场景 pill 切换话术内容
- 话术文本框：显示当前维度+场景的话术
- 操作按钮：
  - "换一换"：刷新话术（当前为动画效果，无实际换话术逻辑）
  - "发送家长"：复制话术到剪贴板，显示 Toast"已复制到剪贴板"
- 学情报告卡片（仅学科使用维度显示）：
  - 标题："小明已完成 4 月 18 日～4 月 25 日的学习"
  - 副标题："快来看看吧"
  - 点击 → 跳转学情周报页

### 3.2 交互规则

| 交互 | 触发 | 结果 |
|------|------|------|
| 点击子女 Tab | Tab 点击 | 切换当前子女，刷新所有卡片数据 |
| 点击"展开" | 日历卡片底部 | 展开完整日历 |
| 点击应用（自研） | 应用条目点击 | 跳转应用足迹·自研（page-footprint-self） |
| 点击应用（三方） | 应用条目点击 | 跳转应用足迹·三方（page-footprint-third） |
| 点击学习计划 | 计划条目点击 | 跳转学习计划详情（page-report-detail） |
| 点击维度 Tab | 维度 Tab 点击 | 切换维度，重置场景为默认 |
| 点击场景 pill | 场景 pill 点击 | 切换场景，更新话术内容 |
| 点击"换一换" | 按钮点击 | 话术淡出淡入动画（当前无实际换话术） |
| 点击"发送家长" | 按钮点击 | 复制话术到剪贴板 + Toast 提示 |
| 点击学情报告卡片 | 卡片点击 | 跳转学情周报（page-student-report） |
| 点击返回按钮 | 导航栏左侧 | 跳转客户详情页（已授权） |

### 3.3 状态说明
- 默认显示第一个子女（张小明）
- 默认维度：基础使用
- 默认场景：提醒督促
- 日历默认收起状态

## 四、导航与跳转

### 4.1 进入路径
- 从客户详情页（已授权）点击"跟进提醒"

### 4.2 离开路径
- 点击应用（自研） → 应用足迹·自研（page-footprint-self）
- 点击应用（三方） → 应用足迹·三方（page-footprint-third）
- 点击学习计划 → 学习计划详情（page-report-detail）
- 点击学情报告卡片 → 学情周报（page-student-report）

### 4.3 返回逻辑
- 导航栏返回按钮 → 客户详情页（已授权）

## 六、异常与边界

### 6.1 空状态
- 无应用使用记录：显示"暂无应用使用记录"
- 无学习计划：显示"暂无学习计划"
- 话术为空：显示"暂无话术"

### 6.2 异常处理
- 应用图标加载失败：显示默认图标
- 复制失败：Toast 提示"复制失败，请手动复制"
- 日历数据异常：显示当前月份空白日历
