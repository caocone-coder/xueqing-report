# 门店服务需求交流会 会议纪要

## 一、会议基本信息
- **会议主题**：门店服务需求（已购客户服务策略与实践分享）交流会
- **会议时间**：2026年04月21日 (周二) 下午 1:50 - 16:46
- **会议时长**：约3小时
- **参会人员**：总部领导、江苏各区域负责人（庞全芳、葛树晶、李木岚、舒老师、王诗雨、刘伟、刘其彬等一线导购代表及大店长）

## 二、会议背景与当前挑战
本次会议旨在探讨和优化科大讯飞学习机已购客户的服务策略。目前终端门店在已购客户维护方面面临以下核心痛点：
1. **复制难度大**：现有优秀的服务模式过度依赖个别大店长或优秀导购的个人能力（如学科规划能力），难以在所有导购和新开门店中规模化复制。
2. **客户时间难匹配**：目标受众以小学和初中生为主，门店需适应其周末或节假日的时间安排，邀约到店的难度随着业务扩展而增加。
3. **“销服一体”导致导购精力透支**：导购不仅要负责前端销售任务，还要承担购机后繁重的日常跟进、学情分析及售后答疑工作，导致服务深度和质量参差不齐。
4. **工具赋能存在短板**：现有的企业微信等工具虽有基础推送功能，但在个性化服务、深度的学情数据获取（如精确的错题数据、正答率、答题时长）及低频用户自动预警等方面依然不足，使得门店缺乏进一步提升服务质量的抓手。

## 三、核心经验与模式分享
各地优秀门店代表分享了各自跑通的实战经验：

### 1. 效果用户墙与口碑营销（庞全芳、葛树晶分享）
- **策略**：在门店建立“效果用户墙”或“效果相册”，展示真实本地用户的使用时间、学校信息及成绩提升点（成功事实）。
- **执行**：强调在购机当下的干预与承诺（如承诺购机一个月内带孩子到店做一次规划学诊断）。这成为销售话术中的标准服务流程，极大提升了客户信任度及转介绍率。

### 2. 深度服务的“15天/21天流程”与“销服分离”（王诗雨、舒老师分享）
- **策略**：探索“销服分离”模式。前端导购专注销售，后端由专人（如店长或专门的教务/服务老师）接手已购用户的深度服务。
- **执行**：
  - **精细化服务周期**：制定15天或21天的标准化跟踪服务流程。Day 1-2 要求家长熟悉功能；Day 4 根据试卷进行学情诊断；后续进行精准功能推荐（如科学实验、AI练习纸、作文批改等）。
  - **VIP群化运营**：为每位购机客户建立专属的VIP小群（拒绝大群运营以防负面情绪蔓延），导购与服务老师协同跟进。
  - **结果导向**：周期结束时（如第11天至第15天），适时索要转介绍，并将其转入常规售后群。

### 3. 高质量的口碑池培育（李木岚分享）
- **策略**：将“效果用户”转变为门店的最高荣誉和VIP池，而非恳求客户配合。
- **执行**：购机时设置入围门槛（如配合发朋友圈、参与21天打卡等），合格者可享受总部及门店的持续福利（伴手礼、奖学金、专属亲子活动、免费以旧换新等）。这极大地增强了高净值客户的品牌粘性。

### 4. 线下办学与陪伴式服务（刘其彬、刘伟分享）
- **策略**：针对周末无暇顾及孩子的“中坚力量”家长，提供门店托管式的陪伴学习服务。
- **执行**：通过邀请购机客户周末带作业到门店集中辅导、利用学习机完成预习和测试，既解决家长痛点，又保障了产品的高频使用率。

## 四、一线的核心诉求与系统工具需求
针对当前的人力瓶颈，一线代表向总部提出了明确的工具优化诉求：
1. **深度的学情数据看板（最核心诉求）**：不仅需要知道客户是否使用了某个功能，更急需看到**具体的学习质量数据**（例如错题量、答题时间、正答率），以便导购/服务人员能够“像老师一样”精准指出孩子的薄弱项，增强服务说服力。
2. **企微与学习机后台打通**：需要自动化的服务进度条管理面板，提示服务人员“某客户处于第几天”、“当前该发送什么内容”；同时增加**低频/高闲置用户的自动预警功能**。
3. **管理权限的灵活开放**：提供纯数据查看的“巡检权限”，方便区域负责人或服务专员跟进所有客户数据，且不与现有的导购销售考核发生冲突。
4. **积分体系与激励工具**：建议完善线上商城的积分兑换机制，把转介绍奖励、打卡奖励兑换为可直接消耗的积分。

## 五、总部的回应与下一步规划
总部针对一线反馈，提出了后续的改进和支持动作：
1. **上线AI客服与工具减负**：已在企微聊天侧边栏上线AI客服工具，能够实时解答基础故障及提供最新话术，直接减轻导购在常规售后上的负担。
2. **推出“规划学”与“日/周报告”系统**：正在打磨一键生成14天/21天学习计划的功能；后续将探索如何在合规且用户授权的前提下，将深度学情报告同步给门店服务人员。
3. **服务品牌化与交付标准化**：计划在全国范围内推广标准化的交付仪式，明确并宣导品牌级别的服务承诺（如每月的服务日、备考期到店辅导等），降低对导购个人拔高能力的依赖。
4. **区域活动支持**：总部将持续下发成熟的“颁奖典礼”、“效果用户分享会”等完整的活动策划和物料包，助力各地门店将深度服务转化为实际的销售口碑和单量。

## 六、关键待办事项 (Action Items)
1. **话术与导图下发**：月底前由相关团队（如李老师团队）整理并下发针对各年龄段的《已购客户跟进话术思维导图》及白话文版供导购演练。
2. **AI客服与规划工具试点**：全体门店近期需配合测试刚上线的AI客服及规划学网页版工具，并向总部反馈实操中的优化建议。
3. **素材库优化**：由金老师等收集各优秀门店的“效果用户墙”真实照片及文案素材，完善总部的标准化推广物料。
4. **服务触达机制落地**：本月起全面落地针对新用户的“首月4次”兜底回访与服务触达机制（通过企微），保证基础服务覆盖率。
5. **客户档案建立标准梳理**：由苏老师等牵头，梳理客户档案建立标准（含学科、成绩、目标等），为后续工具开发提供业务模型支撑。
