## 一、会议背景与目的

本次交流会聚焦**科大讯飞学习机已购客户的门店服务体系建设**，旨在：
1. 收集江苏各区域一线门店在已购客户服务中的实战经验与最佳实践
2. 梳理一线面临的核心困难与工具需求
3. 同步总部在服务工具、品牌化服务方面的规划与进展
4. 探讨"销服分离"模式的可行性与落地路径

## 二、各区域经验分享

### 2.1 南京区域 — 庞全芳（6家门店）

**现状**：
- 服务对象以小学和初中为主，单场1~5人，每组家庭约1小时
- 6家店中3家做得较好（华信等），另外3家因导购专业度不足尚未开展深度服务
- 目前处于"1.0版本"，复制效果不理想

**核心做法**：
- **购机即承诺**：硬性要求导购在售机时告知家长"一个月内必须带孩子到店做规划学诊断"
- **到店服务流程**：先查看孩子一周的学习机使用记录（通过APP端），根据使用情况制定当次学习计划
- **学生分层**：将孩子分为学优生、中等生、学困生，匹配不同功能（AI精准学用于诊断薄弱项、天天练用于基础巩固、AI练习用于专项提升）
- **离店跟进**：及时发送个性化学习规划

**对导购的要求**：
- 对学习机功能的了解度需达到90分以上（满分100）
- 需具备接近老师的专业水平

### 2.2 江苏区域统筹 — 葛树晶

**话术体系建设**：
- 已完成江苏金牌导购颁奖典礼期间的话术研讨与共创
- 按年级段（幼小/小学/初中）分孩子学情，制定情景化挖需话术
- 将输出两个版本：思维导图版（给老板和大店长）+ 白话文话术版（给导购），预计5月初交付

**关键反馈**：
- 强烈需要春季版中小学规划手册（目前仅有秋季版），手册中细分各年级核心知识点及分值占比，对导购谈单帮助极大
- 导购在售后服务中最大的困难是"说不出专业的东西"，企微新上线的规划学功能被认为"正是我们需要的"
- 建议总部给出明确的产品更新周期（如每月固定日期），便于导购向客户承诺
- 讯飞AI学家长端已兼容鸿蒙系统

**关于回访频率的讨论**：
- 总部要求每月4次回访，一线反馈部分客户感到"压力大"、"像被骚扰"
- 建议：频率可保持每周1次，但内容需个性化定制，而非统一模板推送
- 沟通风格要"去官方化"，用"某某爸爸/妈妈"等亲切称呼，结合孩子具体学情进行精准关心

**效果用户墙**：
- 南京门店已在做效果用户墙，标注年级、学校、使用时间、孩子自我感受
- 成本低（几十元），但对逼单环节助力极大——"成功事实"比口头推销更有说服力

### 2.3 盐城区域 — 李木岚（Topsales）

**核心理念**："口碑用户的裂变速度是最快的"

**效果用户运营体系**：
- **筛选机制**：不是所有客户都能成为效果用户，需满足三个条件——①旗舰机用户 ②观念意识好 ③愿意配合
- **荣誉感塑造**：告知家长"效果用户不是谁都能入围的"，通过VIP身份、专属活动邀请、总部直发电影票/礼品等方式提升价值感
- **21天打卡机制**：购机后引导家长每天转发朋友圈+学习打卡，完成后赠送碎屏险/延保（30天内绑定），既养成使用习惯又实现口碑传播
- **转介绍时机**：在打卡快结束前（约第20天），以"业绩压力"为切入点自然邀约转介绍，此时已建立信任链接，成功率高

**VIP群服务内容**：
- 每日晨读卡片（精品制作，非文字复制）
- 新品功能解读视频
- 每周四讯飞家长学院直播精准推送
- 客户档案建立（照片+成绩进步记录）
- 育儿理念分享

**以旧换新**：作为效果用户的会员权益之一，累计达标可免费换新品

**规模化挑战**：个人做效果显著，但超过10家店后复制效果明显下降，需要体系化工具支撑

### 2.4 县级市场 — 舒老师

**已有动作**：
- 建立一对一微信群，日常答疑+问题处理
- 购机一周后开展高频次使用指导课
- 常态化回访跟踪使用情况

**核心需求**：
1. **管理可见性**：大店长/区域负责人看不到下属导购对已购客户的跟进数据和内容，无法判断服务是否到位
2. **学情数据权限**：目前企微只能看到使用频度和板块，看不到掌握度、正确率等深度数据
3. **督学看板**：希望能看到客户使用率，自动提醒低频用户（如一周未使用），避免"买回去沾灰"的负面口碑
4. **客户档案升级**：计划在购机时建立详细档案（年级、辅导班情况、薄弱学科、短期目标分数）

### 2.5 县级市场 — 王诗雨（2家门店，街边店+吾悦店）

**15天深度服务流程**（核心亮点）：

| 天数 | 服务内容 |
|------|----------|
| Day 1-2 | 检测家长/孩子能否熟练找到各科学习功能 |
| Day 3 | 收集孩子试卷，分析各科失分点 |
| Day 4 | 制定个性化学习计划（ABC三联表：A=学生名单、B=15天跟进记录、C=学情规划） |
| Day 5 | 数据跟进，点评鼓励，提醒执行计划 |
| Day 6-7 | 询问使用问题，一对一答疑 |
| Day 8 | 介绍隐藏功能（AI练习纸、PM绘本、科学实验） |
| Day 9 | 重点讲解作文批改功能（附真实案例） |
| Day 10 | 根据使用情况增减调整计划 |
| Day 11 | 邀请二次进店（领资料），促进转介绍 |
| Day 12-13 | 表扬鼓励孩子和家长，数据跟进 |
| Day 14-15 | 发送结束语+后续学习建议，群转为常规售后群 |

**成功案例**：学霸学生刘晓璐，科学从62分提升至67分（满分70），考了年级第二；作文经学习机批改后被老师当范文朗读

**销服分离模式**：
- 导购负责销售，王诗雨个人负责全县深度服务
- 购机后导购拉大群，王诗雨以"学习指导师"身份私发话术邀请家长加入一对一群
- 新购机用户参与深度服务比例约80%
- 从4月份开始尝试一对一建群模式

**最大痛点**：
- 学生基数增多后"自己都乱套了"——不知道每个学生进行到第几天
- 迫切需要**服务进度看板**：打开企微就能看到每个学生的服务阶段、该发什么内容
- 需要看到学生的**深度使用数据**（正确率、答题时间、错题量），而非仅"使用了哪个功能"

### 2.6 邳州 — 刘其彬

**线上服务**：
- 每个已购客户建立5V1或6V1专属群（导购+大店长+家长），确保"谁有空谁第一时间回复"
- 系统更新后第一时间录制视频发群讲解新功能用法

**线下服务**：
- 周四/周五预约进店辅导，一对一或一对二
- 针对"中坚客户"（家长忙、没时间管孩子），主动邀请甚至开车接送孩子到店
- 导购全员"边学边教"，每天啃课本做练习

**核心困难**：
- 低频用户和高闲置用户的筛选完全靠人工，每位导购手里二三百人，逐个排查浪费大量时间
- 部分家长认为系统推送的内容是"广告"，不愿打开

### 2.7 新入职视角 — 刘伟

以"家长+新员工"双重视角提出建议：
- 导购的专业成熟度是客户第一印象的关键，工作量过多会影响专业度
- 转介绍礼品建议更实用（碎屏险、延保优于小礼品）
- 回访时间节点建议集中在考前考后，而非固定频率
- 客户对价格保护（保价）有顾虑，建议明确承诺

### 3.2 品牌化服务权益设计（讨论中）

总部提出将门店服务分为两层：

**第一层：售后服务（基础兜底，所有导购可交付）**
- 每月服务日（第一个周六周日）：配件8折、免费检测
- 新手期30天内每周至少1次主动触达
- 4次基础服务动作（服务承诺再交付、使用问题询问、品牌资料推送、备考提醒）

**第二层：领学服务（个性化升级，有能力的门店/人员交付）**
- 个性化学习规划（借助规划学工具）
- 用户家庭日（结合教育节点：开箱第一课×2次 + 备考期×4次 + 寒暑假×2次）
- 效果用户颁奖典礼（一年4次，结合期中期末考试节点）

## 四、关键共识

1. **"购买才是服务的开始"** — 已购客户服务是口碑裂变和转介绍的核心驱动力，不是可选项
2. **销服分离是趋势** — 销售和服务对人的能力要求不同，长期来看必须分开；短期内可通过"导购做基础服务 + 专人做深度服务"过渡
3. **工具赋能优先于人员培训** — 不能要求所有导购都成为学科专家，应通过规划学工具、AI客服等降低服务门槛
4. **服务需分层** — 全国统一的基础服务（工具化实现）+ 区域个性化的深度服务（有能力的门店升级）
5. **效果外化是关键** — 不能只埋头做服务，必须通过效果用户墙、颁奖典礼、朋友圈传播等方式将服务成果转化为口碑素材
6. **数据驱动服务** — 一线最迫切的需求是"看到数据"，包括学情数据、使用频率、服务进度，这是精准服务的基础

## 六、产品侧重点需求汇总（供督学看板项目参考）

基于本次交流会，一线对"督学看板"类产品的核心需求可归纳为：

### 6.1 数据可见性
- **学情深度数据**：不仅看"用了什么功能"，还要看正确率、答题时间、错题量、掌握度
- **使用频率监控**：自动识别低频/高闲置用户，推送预警提醒给导购
- **日报/周报对导购开放**：目前仅家长端可见，导购需征得授权后查看

### 6.2 服务流程管理
- **服务进度看板**：每个客户处于服务第几天、该执行什么动作，一目了然
- **可定制服务周期**：支持15天/21天/自定义天数的服务流程模板
- **服务完成度追踪**：类似进度条，标记已完成/未完成的服务节点

### 6.3 管理层视角
- **大店长/老板可查看导购跟进情况**：谁跟进了、跟进了什么、效果如何
- **转介绍数据追踪**：哪些客户产生了转介绍、转化率如何

### 6.4 工具集成
- **规划学工具与企微打通**：生成的学习计划可直接在企微中发送和跟踪
- **学习计划导入学习机端内**：家长端生成的计划能自动同步到学习机任务栏（中长期）
- **积分体系**：转介绍可获积分，积分可在讯飞商城兑换配件（建议性需求）
