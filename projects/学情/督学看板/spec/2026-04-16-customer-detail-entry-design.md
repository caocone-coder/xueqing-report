# 客户详情页-学情推荐入口设计文档

## 1. 需求背景

当前督学看板缺少入口页面。导购在企微中的工作流是：客户详情页 → 查看跟进建议 → 执行跟进动作。需要在客户详情页的"跟进内容推荐"区域增加学情推荐模块，作为进入督学看板的入口。

## 2. 放置位置

在客户详情页的"跟进内容推荐"区块内，位于搜索框之前，作为系统推荐的优先跟进内容。

页面结构（不变的部分省略）：

```
客户详情页
  ├── 客户信息区（头像、姓名、标签、描述、加微时间）
  ├── 意向跟进标签
  ├── 成交意向评估（关键用户行为）
  └── 跟进内容推荐
        ├── 【新增】学情推荐卡片
        ├── 话术搜索框
        └── 更多话术 >
```

## 3. 学情推荐模块结构

一张可点击的推荐卡片，包含四部分：

### 3.1 标题行

- 左侧：`学情推荐`
- 右侧：`查看督学看板 >`（点击进入督学看板页面）

### 3.2 推荐摘要

一行结论文案，按状态分三类：

| 状态 | 判定条件 | 文案 |
|------|---------|------|
| 正常 | 无异常规则命中 | 孩子近期使用情况稳定，可查看详细督学报告 |
| 关注 | 命中黄色异常规则（计划完成率低/时长下降/娱乐占比高） | 孩子近期使用出现波动，建议及时跟进 |
| 异常 | 命中红色异常规则（连续未使用>=3天）或存在异常提醒 | 孩子存在明显异常使用行为，建议优先联系家长 |

### 3.3 关键数据行

展示 2-3 个最关键指标：

- 正常状态：本周使用天数 + 暂无异常提醒 + 学习计划完成率
- 关注状态：本周使用天数 + 连续未使用天数 + 学习计划完成率
- 异常状态：异常提醒数 + 最关键的异常描述（如"昨晚 23:30 仍在使用"）

### 3.4 推荐动作行

把系统建议翻译成导购动作：

| 状态 | 推荐动作 |
|------|---------|
| 正常 | 建议：查看报告并发送鼓励型督学话术 |
| 关注 | 建议：提醒家长关注孩子近期使用节奏 |
| 异常 | 建议：优先沟通异常使用行为 |

## 4. 视觉规范

### 4.1 卡片样式

- 白色圆角卡片，与客户详情页其他模块视觉一致
- 标题行：左侧加粗标题 + 右侧蓝色链接文字

### 4.2 状态色

- 正常：绿色圆点标记
- 关注：橙色圆点标记
- 异常：红色圆点标记

### 4.3 推荐动作行

- 灰色底色区块，与数据行视觉区分
- 文字颜色跟随状态色

## 5. 交互逻辑

- 点击卡片任意区域或"查看督学看板 >"均进入督学看板页面
- 若该客户有多个孩子，学情推荐模块展示最需关注的孩子的数据（异常 > 关注 > 正常），进入督学看板后自动定位到该孩子
- 若该客户暂无学习机购机记录，不展示学情推荐模块

## 6. 数据依赖

- 复用督学看板已有的学情数据接口
- 学情推荐模块只需要摘要级数据：使用天数、连续未使用天数、计划完成率、异常提醒数和描述
- 无需新增独立接口，从督学看板接口中取子集即可
