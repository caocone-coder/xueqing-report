# 学情表现文案与数据指标优化方案

**目标：** 
基于《学情表现.xlsx》，将原有的“教研/技术视角”学情文案，全面转化为具有“温度、鼓励感、关怀感”的家长端（C端）沟通语言；同时，精细化拆分“日维度（短平快提醒）”与“周维度（趋势性总结）”的数据触发条件，使方案在产品层面具备高落地性。

**核心设计原则：**
1. **文案转化**：
   - **正向成果类**：强化荣誉感与进步感（如“薄弱点攻克小达人”）。
   - **负向/建议类**：弱化指责，强化关怀与具体的行动建议（如将“异常作答行为”改为“答题节奏小提醒”）。
2. **日/周维度指标设计**：
   - **日维度（短周期）**：注重**即时反馈**，阈值较低，突出“今天”发生了什么，建议家长“今晚”怎么做。
   - **周维度（长周期）**：注重**趋势判断与习惯养成**，阈值较高，需包含累计计算或天数统计，突出“本周”整体表现，建议家长“周末”做何规划。

---

### 优化明细与执行拆解

#### 任务 1：学习成果类（正向激励）
原分类：“消除薄弱点/思维n个”、“一口气掌握了n个知识点”

- **1.1 薄弱点攻克**
  - **新名称（C端可见）**：薄弱点清扫计划 / 攻克小达人
  - **日维度模板**：“今天成功攻克了[学科]的[n]个薄弱知识点，宝贝很棒，请继续保持哦！”
    - *日触发条件*：当日掌握程度由 <60% 提升至 ≥80% 的知识点数量 [n] ≥ 1个。
  - **周维度模板**：“本周稳扎稳打，累计清扫了[n]个薄弱盲区，知识基础越来越扎实啦！”
    - *周触发条件*：本周累计消除薄弱点数量 [n] ≥ 3个。

- **1.2 知识点掌握**
  - **新名称（C端可见）**：知识吸收小海绵
  - **日维度模板**：“今天学习效率超高，一口气扎实掌握了[n]个新知识！”
    - *日触发条件*：当日新掌握知识点 [n] ≥ 3个。
  - **周维度模板**：“本周学习状态拉满，共掌握了[n]个知识点，进步看得见！”
    - *周触发条件*：本周累计掌握知识点 [n] ≥ 10个。

#### 任务 2：学习习惯与作答类（温和提醒）
原分类：“作答习惯：快速作答”、“修改批改结果”、“专注度不足”、“用眼需关注”

- **2.1 作答习惯异常**
  - **新名称（C端可见）**：答题节奏小提醒
  - **日维度模板**：“发现宝贝今天有[n]道题做题速度有些‘飙车’（直接跳过或过快提交），建议关注下是不是遇到了不会的题哦~”
    - *日触发条件*：当日异常作答（跳过或快速点击）的题目数量 [n] ≥ 2题。
  - **周维度模板**：“本周有[n]次做题偏快或直接跳过，周末可以和宝贝聊聊，培养耐心读题的习惯会更好哦。”
    - *周触发条件*：本周累计异常作答题目数量 [n] ≥ 5题。

- **2.2 专注度表现**
  - **新名称（C端可见）**：专注力守护
  - **日维度模板**：“今天连续专注学习最长仅[n]分钟，可以帮宝贝把任务拆解成小块，完成一块休息一下，更有成就感哦。”
    - *日触发条件*：当日最长连续专注时长 [n] < 15分钟，且有学习行为。
  - **周维度模板**：“本周有[n]天学习时稍微有些坐不住，周末带宝贝好好放松一下，下周再接再厉培养专注力。”
    - *周触发条件*：本周满足“单日连续专注<15分钟”的天数 [n] ≥ 3天。

- **2.3 用眼健康**
  - **新名称（C端可见）**：护眼小卫士
  - **日维度模板**：“今天用眼有些疲劳啦（距离屏幕太近或时间过长），记得提醒宝贝遵循‘20-20-20’法则，向远看放松一下眼睛哦！”
    - *日触发条件*：当日系统判定用眼状态为“不佳”。
  - **周维度模板**：“本周有[n]天都没保护好眼睛哦，周末多安排一些户外活动，让眼睛彻底放个假吧。”
    - *周触发条件*：本周用眼不达标的天数 [n] ≥ 3天。

#### 任务 3：错题消化类（痛点跟进）
原分类：“审题失误需重视”、“错题原因未分析”

- **3.1 审题失误**
  - **新名称（C端可见）**：粗心小雷达
  - **日维度模板**：“今天有[n]道题因为没看清题意丢分啦，下次做题可以试试带着宝贝一起‘圈出关键词’哦。”
    - *日触发条件*：当日因“审题有误”导致的错题数量 [n] ≥ 2题。
  - **周维度模板**：“本周累计有[n]道题‘败’给了审题，周末可以让宝贝当小老师给你讲讲题目，锻炼仔细读题的好习惯。”
    - *周触发条件*：本周累计因“审题有误”导致的错题数量 [n] ≥ 8题。

- **3.2 错因未分析**
  - **新名称（C端可见）**：错题本小管家
  - **日维度模板**：“今天新增了[n]道错题还没寻找原因，找出‘为什么错’比光知道‘正确答案’更管用哦。”
    - *日触发条件*：当日新增且未分析错因的错题数量 [n] ≥ 5题。
  - **周维度模板**：“本周还有[n]道错题等着被‘复盘’，周末花点时间一起分析下错因，能有效避免下次踩坑。”
    - *周触发条件*：本周累计新增且未分析错题数量 [n] ≥ 20题。

#### 任务 4：素养发展类（综合素质）
原分类：“好久没画画啦/没敲代码啦/没做实验啦/没动啦”

- **4.1 综合素养关怀**
  - **新名称（C端可见）**：艺体探索/运动打卡提醒
  - **日维度模板**：（体能类专属）“今天还没进行运动打卡哦，身体都要‘生锈’啦，快拉上爸爸妈妈一起动一动！”
    - *日触发条件*：当日无运动打卡记录。
  - **周维度模板**：“这周好像太忙啦，好久没[拿起画笔/探索奇妙现象/敲代码]了，周末抽空体验一下，灵感会更棒哦！”
    - *周触发条件*：上周对应素养活跃度 ≥ 1，且本周活跃度为 0。
