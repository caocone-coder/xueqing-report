# 学习成果详情页统一组件规范

## 1. 概述

基于学情表现 Excel 文件的分析，学习成果共有 **29 种不同的详情页**，涉及 **8 大内容类型**。为了降低开发和维护成本，本文档提炼出统一的组件规范，通过组合基础组件来构建各类详情页。

## 2. 详情页分类统计

| 内容类型 | 详情页数量 | 学习成果数量 | 占比 |
|---|---|---|---|
| 知识点类 | 2 | 6 | 12% |
| 题目类 | 5 | 12 | 24% |
| 课程类 | 3 | 5 | 10% |
| 语文专项类 | 6 | 9 | 18% |
| 英语专项类 | 2 | 2 | 4% |
| 计划类 | 2 | 2 | 4% |
| 作品类 | 3 | 3 | 6% |
| 统计类 | 5 | 7 | 14% |
| 其他类 | 1 | 1 | 2% |
| **合计** | **29** | **47** | **100%** |

## 3. 统一组件体系

### 3.1 页面结构组件

所有详情页采用统一的页面结构：

```
┌─────────────────────────────────────────────┐
│ [导航栏]                                     │
├─────────────────────────────────────────────┤
│ [页面头部组件]                               │
│  - 标题                                      │
│  - 统计数据卡片                              │
│  - 筛选器（可选）                            │
├─────────────────────────────────────────────┤
│ [内容列表组件]                               │
│  - 列表项 1                                  │
│  - 列表项 2                                  │
│  - ...                                       │
├─────────────────────────────────────────────┤
│ [空态组件]（无数据时展示）                   │
└─────────────────────────────────────────────┘
```

### 3.2 基础组件库

#### 3.2.1 导航栏组件 (NavigationBar)

**用途：** 所有详情页通用

**结构：**
```
┌─────────────────────────────────────────────┐
│ [<返回] 页面标题                    [更多]   │
└─────────────────────────────────────────────┘
```

**参数：**
- `title`: 页面标题（必填）
- `showMore`: 是否显示"更多"按钮（可选）
- `onBack`: 返回按钮点击事件

---

#### 3.2.2 统计卡片组件 (StatCard)

**用途：** 展示关键统计数据

**样式：**
```
┌─────────────────────────────────────────────┐
│  本周掌握知识点                              │
│  15 个                                       │
│  较上周 +5                                   │
└─────────────────────────────────────────────┘
```

**参数：**
- `label`: 统计项名称
- `value`: 统计值
- `trend`: 趋势（可选，如 "+5"）
- `trendType`: 趋势类型（"up" | "down" | "neutral"）

---

#### 3.2.3 筛选器组件 (FilterBar)

**用途：** 内容筛选和排序

**样式：**
```
┌─────────────────────────────────────────────┐
│ [全部学科 ▼] [本周 ▼] [掌握度 ▼]           │
└─────────────────────────────────────────────┘
```

**参数：**
- `filters`: 筛选项配置数组
  - `type`: 筛选类型（"dropdown" | "tabs"）
  - `options`: 选项列表
  - `defaultValue`: 默认值

---

#### 3.2.4 列表项组件 (ListItem)

**用途：** 展示列表内容，支持多种内容类型

**通用结构：**
```
┌─────────────────────────────────────────────┐
│ [图标/缩略图]  标题                      >   │
│                副标题/描述                   │
│                [标签1] [标签2]               │
└─────────────────────────────────────────────┘
```

**参数：**
- `icon`: 左侧图标（可选）
- `thumbnail`: 缩略图（可选）
- `title`: 主标题（必填）
- `subtitle`: 副标题（可选）
- `description`: 描述文字（可选）
- `tags`: 标签数组（可选）
- `rightContent`: 右侧内容（可选，如进度、分数）
- `onClick`: 点击事件

---

#### 3.2.5 空态组件 (EmptyState)

**用途：** 无数据时的占位提示

**样式：**
```
┌─────────────────────────────────────────────┐
│                                              │
│              [空态图标]                      │
│                                              │
│           暂无相关数据                       │
│      快去学习机上开始学习吧～                │
│                                              │
│           [去学习]                           │
│                                              │
└─────────────────────────────────────────────┘
```

**参数：**
- `icon`: 空态图标
- `title`: 空态标题
- `description`: 空态描述
- `actionText`: 按钮文字（可选）
- `onAction`: 按钮点击事件（可选）

## 6. 技术实现建议

### 6.1 组件库技术栈

- **框架：** React / Vue（根据项目技术栈选择）
- **样式：** CSS Modules / Styled Components
- **图表：** ECharts / Chart.js
- **状态管理：** Redux / Vuex（如需要）

### 6.2 组件开发优先级

| 优先级 | 组件 | 原因 |
|---|---|---|
| P0 | 导航栏、统计卡片、列表项、空态组件 | 所有页面必需，复用率 100% |
| P1 | 筛选器 | 复用率 87.5%，大部分页面需要 |
| P2 | 图表组件、宫格布局 | 特定页面需要 |
