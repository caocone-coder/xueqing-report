# 学习成果详情页设计规范

## 一、设计目标

为家长端学习成果报告设计 8 类详情页，统一信息层级与视觉语言，同时保留各分类的差异化表达。

**核心原则**
- 中度统一：统一头部、概览卡、留白和信息层级
- 差异化表达：列表区按分类保留自己的表现形式
- 家长视角：用家长能理解的语言解读数据

**交付物**
- 8 个独立详情页 HTML（单页沉浸式）
- 1 个聚合演示页 HTML（横向切换 8 类）

---

## 二、统一骨架

### 2.1 页面结构

所有详情页采用统一的三段式结构：

```
┌─────────────────────────────────┐
│ 顶部导航栏                        │
│ ← 学习成果详情                    │
├─────────────────────────────────┤
│ 首卡（概览卡）                    │
│ ├ 成果标题 (16px/600)            │
│ ├ 一句总结 (14px/400)            │
│ ├ 指标区 (2x2 网格，3-4 个指标)  │
│ └ 家长解读 (14px/400)            │
├─────────────────────────────────┤
│ 第二张卡（本周完成内容）          │
│ └ 按分类变化                     │
├─────────────────────────────────┤
│ 第三张卡（更细明细）              │
│ └ 按分类变化                     │
└─────────────────────────────────┘
```

### 2.2 字号层级

| 元素 | 字号 | 字重 | 颜色 |
|------|------|------|------|
| 页面栏标题 | 17px | 500 | #1f2229 |
| 首卡标题 | 16px | 600 | #1f2229 |
| 其它卡片标题 | 16px | 600 | #1f2229 |
| 内容标题 | 15px | 600 | #1f2229 |
| 正文 | 14px | 400 | #656a73 |
| 辅助文字 | 12px | 400 | #999da6 |
| 指标标签 | 11px | 400 | #999da6 |
| 指标数值 | 32-34px | 700 | #1f2229 |

### 2.3 间距与留白

- 页面外边距：`padding: 0 12px`
- 卡片间距：`gap: 12px`
- 卡片内边距：`padding: 16px 14px`
- 卡片圆角：`border-radius: 16px`
- 指标卡圆角：`border-radius: 12px`
- 指标卡间距：`gap: 10px`

### 2.4 色彩系统

**主色**
- 成功/正向：`#52c41a`（绿色）
- 数据/中性：`#38afff`（蓝色）
- 警示/负向：`#ff6509`（橙色）
- 文字主色：`#1f2229`
- 文字辅助：`#656a73`
- 文字次要：`#999da6`

**背景色**
- 页面背景：`#f3f4f6`
- 卡片背景：`#fff`
- 指标卡背景：`#f7f7f9`
- 顶部渐变：`linear-gradient(180deg, #ddf5ea 0%, #f3f4f6 100%)`

## 三、8 类详情页设计

### 3.1 阅读详情页

**首卡指标（2x2）**
1. 本周阅读时长（分钟）
2. 累计词汇量（个）
3. 当前阅读等级（Level）
4. 单词测试正确率（%）

**第二张卡：本周已读绘本**
- 书籍封面缩略图（46x62px）
- 书名 + 等级标签
- 出版社 + 词数
- 完成状态标签（听读、跟读、测试）
- 阅读时长（右侧大数字）

**第三张卡：本周新增词汇掌握情况**
- 3 个统计指标（测试词数、错误词数、正确率）
- 词汇网格（4 列，错误词标红）

---

### 3.2 知识点/单元详情页

**首卡指标（2x2）**
1. 新掌握知识点（个）
2. 平均掌握度（%）
3. 提升幅度（%）
4. 当前等级/状态

**第二张卡：本周掌握知识点**
- 知识点名称
- 掌握度进度条（带百分比）
- 进步说明（从 X% 提升到 Y%）

**第三张卡：单元达标情况**
- 单元名称 + 达标标识
- 单元内知识点统计
- 综合评价

---

### 3.3 错题详情页

**首卡指标（2x2）**
1. 已攻克错题（道）
2. 订正率（%）
3. 最高频错因（文字）
4. 待巩固错题（道）

**第二张卡：本周订正错题**
- 具体题目内容（完整题干）
- 错因标签 + 订正状态标签
- 错误原因说明（左侧橙色边框）
- 右侧箭头（可点击跳转）

**第三张卡：错因分布**
- 2 列网格展示各错因统计

---

### 3.4 试题练习详情页

**首卡指标（2x2）**
1. 答对题数（题）
2. 正确率（%）
3. 最高连对（题）
4. 完成题包/试卷（个）

**第二张卡：本周练习表现**
- 题包/试卷名称
- 等级标识（A/B/C 或试卷图标）
- 正确率 + 完成时间
- 进步说明

**第三张卡：连对记录**
- 连对题数 + 日期
- 所属单元/知识点
- 状态说明

---

### 3.5 课程任务详情页

**首卡指标（2x2）**
1. 完成任务（节）
2. 课程学习（个）
3. 完成率（%）
4. 预习任务（节）

**第二张卡：本周学习任务**
- 课程名称（如"数学：圆的认识与应用"）
- 阶段名称 + 时间段
- 进度条 + 完成百分比
- 练习正确率 + 知识点掌握情况（2 个小指标）
- 任务说明

**第三张卡：课程学习投入**
- 2 列统计（语文课程、预习任务）
- 投入说明

---

### 3.6 字词背诵详情页

**首卡指标（2x2）**
1. 答对字词（个）
2. 背诵课文（篇）
3. 最高分（分）
4. 平均分（分）

**第二张卡：本周新增字词**
- 字词云展示（横向排列，圆角标签）
- 积累说明

**第三张卡：课文背诵记录**
- 课文名称
- 背诵分数（右侧大数字）
- 完成时间 + 状态
- 点评

---

### 3.7 作文详情页

**首卡指标（2x2）**
1. 高分作文（篇）
2. 最高分（分）
3. 平均分（分）
4. 提升幅度（分）

**第二张卡：本周作文表现**
- 作文标题
- 批改时间
- 作文分数（右侧大数字）
- 点评内容（左侧绿色边框）
- 进步标签
- 右侧箭头（可点击跳转）

**第三张卡：改进建议**
- 具体建议文字

---

### 3.8 素养作品详情页

**首卡指标（2x2）**
1. 作品数量（个）
2. 交流次数（次）
3. 通关数量（关）
4. 创作时长（分钟）

**第二张卡：本周创作作品**

**绘画作品示例**
- 2 列网格展示作品缩略图
- 作品名称
- 作品类型 + 完成时间

**编程作品示例**
- 2 列网格展示代码片段样式
- 作品名称
- 技术栈 + 运行状态

**第三张卡：创作过程表现**

**绘画作品**
- 完成作品数、创作时长、AI 交流次数
- 创作评价

**编程作品**
- 完成作品数、代码调试次数、运行成功率
- 编程评价

## 四、交互规范

### 4.1 可点击元素

**视觉暗示**
- 右侧箭头 `›`（18px，#b2b6bd）
- hover 时边框变蓝（`border: 1px solid #d4ebff`）
- cursor: pointer

**适用场景**
- 错题列表项（跳转到错题详情）
- 作文卡片（跳转到作文详情）
- 课程任务卡片（跳转到任务详情）
- 作品卡片（跳转到作品详情）

### 4.2 状态标签

**标签样式**
- 圆角：`border-radius: 8px`
- 内边距：`padding: 2px 8px`
- 字号：`11px`

**标签色彩**
- 成功/已完成：`background: #e8f5ff; color: #1098f3`
- 警示/错误：`background: #fff1f0; color: #ff6509`
- 中性/待处理：`background: #f7f7f9; color: #999da6`

## 六、设计验收标准

### 6.1 视觉一致性
- [ ] 所有页面字号层级统一
- [ ] 所有页面间距留白统一
- [ ] 所有页面色彩使用统一
- [ ] 所有页面圆角规范统一

### 6.2 信息层级
- [ ] 首卡承担"家长先看懂发生了什么"
- [ ] 第二卡展示本周完成内容
- [ ] 第三卡展示更细明细
- [ ] 所有页面控制在 3 张主卡内

### 6.3 交互体验
- [ ] 可点击元素有明确视觉暗示
- [ ] hover 效果流畅自然
- [ ] 状态标签色彩语义清晰

### 6.4 内容表达
- [ ] 家长向文案通俗易懂
- [ ] 数据解读有具体说明
- [ ] 进步点明确突出
