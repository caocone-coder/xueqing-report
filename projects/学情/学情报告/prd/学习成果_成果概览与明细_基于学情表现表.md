来源表格：`/Users/a1-6/CC_project/projects/学情/学情报告/学情表现/学情表现_最终版_20260428_1728.xlsx`

适用范围：日报、周报中的“学习成果”卡片及对应 8 类独立详情页。

## 1. 展示原则

| 原则 | 说明 |
| --- | --- |
| 面向家长表达 | 页面只展示孩子本周/今日做得更好的地方，不展示触发阈值、去重规则、统计口径、ID、默认展示逻辑等内部说明 |
| 概览先看进步 | 成果概览必须包含关键数据和变化表达，例如多掌握了几个、正确率更稳、阅读更主动、任务更连续 |
| 明细承接证据 | 成果详情展示能支撑该成果的具体对象，例如知识点、错题、课文、课程、书籍、作文、作品 |
| 多学科分开展示 | 若同一成果涉及多个学科，概览展示整体进步，明细按学科分组或学科 Tab 展示 |
| 单条可下钻 | 若明细对象有原业务详情页，整条明细保留可达状态；前端文案不解释“如何进入” |
| 无明细兜底 | 若只有汇总数据没有明细对象，展示成果概览和轻量提示，不展示空列表 |

## 4. 页面文案要求

| 位置 | 要求 | 示例 |
| --- | --- | --- |
| 成果概览标题 | 使用成果名称或更自然的家长端标题 | “知识点学扎实了”“阅读习惯在养成” |
| 成果概览副标题 | 只描述本周/今日表现，不写规则说明 | “本周掌握变化”“阅读投入与词汇积累” |
| 关键指标 | 使用 2-3 个家长能理解的数据 | “新掌握 6 个”“正确率 88%”“阅读 2小时18分” |
| 变化看点 | 用短句解释进步 | “比上周多掌握 3 个知识点”“阅读主动性更好了” |
| 成果明细标题 | 使用对象名称，不写操作说明 | “本周错题明细”“本周已读绘本”“本周作文表现” |
| 单条明细 | 展示对象本身和进步证据 | “圆的半径与直径：现在做题更稳了” |

## 5. 多学科展示要求

| 场景 | 展示方式 |
| --- | --- |
| 概览涉及多个学科 | 只表达整体进步，例如“这周多个学科都有明显进步” |
| 明细涉及多个学科 | 使用学科分组或学科 Tab，当前分组标题直接展示学科名 |
| 单学科成果 | 不展示多学科说明，只展示该学科成果 |
| 素养类成果 | 按作品类型展示，例如绘画、编程、数独，不强行套学科结构 |
