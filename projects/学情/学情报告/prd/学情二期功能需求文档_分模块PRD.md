## 0. PRD 总览

### 0.1 背景与目标

本期需求围绕学情报告二期能力升级，目标是让家长更容易理解孩子真实学习情况，并通过报告内容带动推荐应用、学习计划和学情分享的使用。

核心目标:

- 提升有效报告查看率: 根据孩子真实学习情况提供有针对性的报告内容。学得多的孩子突出重点、进步和薄弱点；学得少的孩子也提供可执行的学习建议。
- 提升推荐应用/学习计划使用率: 通过学习成果、学习建议和推荐卡片，让家长理解自研应用优势及适用场景。
- 提升学情内容分享率: 通过学情分享功能，让家长展示孩子学习成果，形成口碑传播。

### 0.2 需求来源

- 产品规划

## 2. M1 学情报告基础与学情总结

### 2.1 模块目标

在日报/周报详情页提供“学情总结”能力，用简洁的总结文案、表现标签、学习时长和应用使用情况帮助家长理解孩子当前阶段的学习表现。

### 2.2 适用范围

| 项 | 说明 |
| --- | --- |
| 适用版本 | App 版本 ≥ V4.0.0 |
| 低版本策略 | 低版本不展示此模块，不做兼容处理 |
| 报告范围 | 日报、周报 |
| 入口 | 学习 tab 页点击【日报周报】进入报告页；点击学情报告消息进入报告页 |
| 端 | App 展示报告；学习机端承接鼓励回复能力 |

### 2.3 展示与生成规则

| 场景 | 规则 |
| --- | --- |
| 首次生成报告且无历史数据 | 不展示学情总结标签 |
| 日报 | 当日 24:00 后生成并展示“学情总结”标签，覆盖当日 00:00-24:00 学习数据 |
| 周报 | 每周日 24:00 后生成并展示“学情总结”标签，覆盖周一 00:00-周日 24:00 学习数据 |
| 评分规则 | 待数据分析同学给出具体分值参考 |
| 标签维护 | 标签映射评分规则按学期内数据动态维护 |

### 2.4 学情总结标签映射

| 综合评分 | 标签文字 | 家长鼓励按钮文案 | 学习机回复 emoji |

| 85-100 分 | 表现完美 | 宝贝表现成绩斐然！超给力的，快和宝贝击个掌～ | 💯 |
| 75-84 分 | 进步飞快 | 宝贝进步超明显！超有潜力！快给宝贝点个赞～ | ❤️ |
| 65-74 分 | 稳步前进 | 学习节奏超稳的！快送上一份爱的鼓励吧～ | ❤️ |
| 55-64 分 | 继续保持 | 稳住这份状态！坚持下去就有大收获，狠狠夸一波～ | 🤗 |
| 45-54 分 | 相信自己 | 宝贝超有潜力别怀疑！来抱抱宝贝，再努努力就突破啦～ | 😘 |
| 35-44 分 | 请加油哦 | 加把小油～跟着节奏走，问题都能搞定，陪宝贝一起冲～ | 💪 |

### 2.5 页面信息架构

报告页建议按以下结构组织:

| 区域 | 内容 |
| --- | --- |
| 顶部信息 | 孩子头像、孩子昵称、日报/周报切换、日期范围 |
| 本周/今日总结 | 总结文案、进步点、薄弱点、家长行动建议 |
| 使用时长 | 总学习时长、对比上周期变化、按日期趋势图 |
| 应用使用情况 | 自研应用、三方应用分类，展示重点应用和使用时长 |
| 学情表现标签 | 根据综合评分展示标签，并连接家长鼓励文案 |
| 后续模块 | 学习成果、学习建议、本周/今日任务、分享入口 |

### 2.6 Demo 内容参考

自研学情活跃案例 Demo 中，示例用户“小丸子”的周报包含:

- 本周总结: 使用时长相比上周增加，数学精力投入突出，答题正确率进步明显；词汇掌握相对薄弱，建议家长关注并帮助巩固单词。
- 使用时长: 58 小时 54 分钟，相比上一周提升 5%。
- 应用使用: 自研应用 5 个，三方应用 1 个；展示瑞恩熊 AI 英语、分级阅读、新概念英语等使用时长。
- 学习成果: 数学答题正确率提升、英语分级阅读完成量、语文字词练习连续打卡。
- 学习建议: 英语词汇掌握偏弱、数学知识点需巩固。
- 学科学习情况: 语文、数学、英语、物理、化学、生物、道法等学科切换和细分指标。

## 3. M2 家长鼓励

### 3.1 模块目标

将学情总结中的正向反馈转化为家长对孩子的鼓励动作，并让孩子在学习机端收到鼓励、回复表情，形成双端情感反馈闭环。

### 3.2 业务流程

| 步骤 | 端 | 行为 | 结果 |
| --- | --- | --- | --- |
| 1 | App | 家长在报告页点击鼓励入口或鼓励按钮 | App 发送鼓励消息 |
| 2 | 学习机 | 孩子收到鼓励消息 | 展示鼓励弹窗或蒙层 |
| 3 | 学习机 | 孩子点击消息并选择表情回复 | 学习机发送回复结果 |
| 4 | App | 家长查看孩子回复 | App 展示孩子回复的 emoji 或反馈状态 |

### 3.3 文案来源

家长鼓励按钮文案与 M1 学情总结标签映射相关联。不同综合评分对应不同鼓励文案和学习机回复 emoji。

## 4. M3 学习成果与学习建议

### 4.1 模块目标

在报告中展示孩子阶段性学习成果，并根据孩子学习行为、薄弱项、时间节点和相似榜样用户模型生成学习建议，带动自研应用和学习计划使用。

### 4.2 适用范围

| 项 | 说明 |
| --- | --- |
| 适用版本 | App 版本 ≥ V4.0.0 |
| 入口 | 学习 tab 页点击日报周报按钮进入报告页 |
| 报告范围 | 日报、周报 |
| 依赖授权 | 学习建议涉及用户学习报告信息授权 |
| 子能力 | 学习成果、学习建议、应用推荐、计划推荐、榜样模型推荐 |

### 4.3 学习成果展示规则

| 项 | 规则 |
| --- | --- |
| 展示条件 | 本周/当日使用时长 ≥ 5 分钟，且学情应用时长占比 ≥ 50% |
| 模块标题 | 学习成果 |
| 模块描述 | 任何进度都值得表扬，快去夸夸宝贝吧~ |
| 展示数量 | 1-5 项 |
| 展示要素 | 成果图标、成果标题、具体描述 |
| 判定优先级 | 掌握知识 > 计划达成 > 坚持学习 > 练习出色 > 积累知识 > 复习到位 > 错题巩固 > 习惯良好 |

### 4.4 学习建议授权规则

学习建议开启前需用户同意《科大讯飞AI学习机用户学习报告信息授权》。

授权内容摘要:

| 类别 | 内容 |
| --- | --- |
| 基础信息 | 孩子头像、昵称 |
| 学习行为数据 | 学习机绑定关联时间、设备及应用使用时长、应用使用记录等 |
| 数据统计周期 | 从学习机绑定时间开始 |
| 使用目的 | 仅用于学习报告生成与展示 |
| 公开展示风险 | 如果用户转发、分享、公开展示报告页面或截图，他人可能看到头像、昵称、学习机使用和学习相关数据 |
| 算法提示 | 学习建议基于学习记录自动生成，可能与实际情况存在偏差，无法保证展示数据绝对准确 |

### 4.5 学习建议展示规则

| 场景 | 规则 |
| --- | --- |
| 常规周报 | 本周使用时长 ≥ 5 分钟时可展示学习建议 |
| 近 4 周偶尔使用 | 本周使用时长 < 5 分钟，但过去 4 周内存在至少 1 周使用时长 ≥ 5 分钟，可展示建议 |
| 低数据量场景 | 应避免空洞结论，优先给出下一步可执行建议 |
| 授权缺失 | 未同意授权时不展示个性化学习建议，需展示授权引导或隐藏模块 |

### 4.6 推荐类型与权重

不同学情场景下，APP、PLAN、MODEL 三类推荐对象权重不同。

| 场景 | 优先级 | 推荐类型权重 |
| --- | --- | --- |
| 常用自研学情 | APP > PLAN > Model | APP 0.5、PLAN 0.4、Model 0.1 |
| 常用三方应用 | APP > PLAN > Model | APP 0.5、PLAN 0.4、Model 0.1 |
| 常用自研非学情应用 | PLAN > APP > Model | PLAN 0.5、APP 0.3、Model 0.2 |
| 偶尔使用学习机 | Model > PLAN > APP | Model 0.7、PLAN 0.2、APP 0.1 |

### 4.7 推荐算法

#### APP 推荐得分

| 项 | 公式/说明 |
| --- | --- |
| 总得分 | `S_total = [Σ i=1..4 (S_rule-i × W_rule-i × W_scene-i)] × W_feedback` |
| 含义 | 应用的最终推荐总得分，得分越高优先级越高 |
| 取值范围 | 0-100 |
| 统计维度 | 计算 |

#### PLAN 推荐得分

| 项 | 公式/说明 |
| --- | --- |
| 总得分 | `S_total = [Σ i=1..2 (S_rule-i × P_scene-i)] × W_feedback` |
| 含义 | 计划的最终推荐总得分，得分越高优先级越高 |
| 取值范围 | 0-100 |
| 规则维度 | `i=1` 为时间节点，`i=2` 为薄弱学科 |

#### MODEL 推荐得分

| 项 | 公式/说明 |
| --- | --- |
| 总得分 | `S_total = [(M_similar × 0.5) + (M_progress × 0.3) + (M_recent × 0.2)] × W_feedback × 100` |
| M_similar | 榜样用户匹配权重，0-1 |
| M_similar 计算 | 年级 0.3 + 学科 0.3 + 机型 0.2 + 城市 0.1 + 使用天数 0.1 |
| M_progress | 成效学科优先级权重，0 或 1 |
| M_progress 规则 | 榜样用户的成效学科与薄弱学科匹配时为 1，不匹配为 0 |

## 5. M4 本周/今日任务

在日报/周报详情页聚合孩子当前周期内的学习计划和作业任务，让家长在报告中直接看到任务进度，并引导孩子继续完成任务。

### 5.2 适用范围

| 项 | 说明 |
| --- | --- |

## 9. M8 数据看板与埋点

### 9.1 模块目标

### 9.2 统计需求

#### 9.2.1 学情看板字段

| 字段 | 口径定义 | 对应看板功能 |
| --- | --- | --- |
| 学情触达 | 整体: 汇总主动、被动和分享。目前按汇总数据计算，如需变成维度，数据需从底层改造。主动: 在 AI 学 App 主动查看。被动: push 消息和微信服务通知。分享: 点击或扫码分享的小程序卡片进入相关学情页。 | 筛选项 |
| 学情类型 | 整体: 汇总足迹、日报和周报。单一: 足迹/日报/周报。组合: 报告，即日报或周报。 | 筛选项 |

#### 9.2.2 有效学情占比

| 项 | 规则 |
| --- | --- |
| 定义 | 统计周期内，每个孩子每天最多计 1 份学情报告 |

| 公式 | 有效学情占比 = 有效学情报告份数 / 总学情报告份数 |
| 去重要求 | 分子和分母均需去重 |

#### 9.2.3 学情查看率

| 项 | 规则 |
| --- | --- |
| 定义 | 统计周期内，每天每个孩子最多计 1 次查看行为 |
| 报告类型 | 不区分日报或周报 |
| 多次查看 | 同一天内多次查看只计 1 次 |
