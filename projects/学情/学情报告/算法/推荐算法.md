推荐算法（学习建议融合版）

# 一、总体评分框架

推荐对象分为学习机应用和学习计划。学习建议作为意图层参与召回和排序，原 5 条推荐规则继续作为通用排序依据。

当用户触发有效学习建议时：

$$S_{total} = \left[S_{advice} \times 0.40 + S_{origin} \times 0.45 + S_{object} \times 0.15\right] \times W_{feedback} \times W_{fatigue} \times W_{valid}$$

当用户没有触发有效学习建议时：

$$S_{total} = S_{origin} \times W_{feedback} \times W_{fatigue} \times W_{valid}$$

其中：

| 参数 | 含义 | 取值范围 |
| :--- | :--- | :--- |
| $$S_{total}$$ | 最终推荐总分，得分越高越优先 | 0-100 |
| $$S_{advice}$$ | 学习建议驱动分，用于表达当前问题和建议配置对象的匹配度 | 0-100 |
| $$S_{origin}$$ | 原 5 条规则综合分 | 0-100 |
| $$S_{object}$$ | 推荐对象自身适配分，用于区分应用和计划的属性匹配程度 | 0-100 |
| $$W_{feedback}$$ | 用户反馈权重 | 0-1 |
| $$W_{fatigue}$$ | 曝光疲劳和去重权重 | 0-1 |
| $$W_{valid}$$ | 可推荐校验权重，不满足过滤条件时为 0 | 0 / 1 |

# 二、学习建议驱动分

$$S_{advice} = \left(W_{trigger} \times 0.35 + W_{priority} \times 0.25 + W_{match} \times 0.25 + W_{config} \times 0.15\right) \times 100$$

| 参数 | 含义 | 取值规则 |
| :--- | :--- | :--- |
| $$W_{trigger}$$ | 建议触发强度 | 指标越超过触发阈值越高；二值型触发取 1 |
| $$W_{priority}$$ | 学习建议展示优先级 | $$(24 - priority) / 23$$，优先级 1 最高 |
| $$W_{match}$$ | 用户画像匹配度 | 学科 0.4 + 学段/年级 0.3 + 场景 0.2 + 难度 0.1 |
| $$W_{config}$$ | 建议配置强度 | 明确应用包名 1；明确专项计划 0.8；所有学习计划 0.7；策略兜底 0.4；无配置且不召回 0 |

## 触发强度计算

- 数量越大越严重的指标：$$W_{trigger} = min(1, actual / threshold)$$
- 正确率、完成率、阅读时长等低于阈值的指标：$$W_{trigger} = min(1, (threshold - actual) / threshold + 0.5)$$
- 学习间隔、计划落后天数：$$W_{trigger} = min(1, actual / 7)$$
- 护眼健康提醒和运动提醒不参与学习应用/计划排序，$$W_{config}=0$$。

## 多建议合并

同一用户同一统计周期最多取 3 条学习建议参与排序：

1. 先按展示优先级升序排序。
2. 再按触发强度降序排序。
3. 同一学科多条建议同时触发时，保留最高分建议作为主原因，其余作为加分原因。

多个学习建议命中同一对象时：

$$S_{advice-final} = max(S_{advice}) + 5 \times (N_{hit} - 1)$$

其中 $$N_{hit}$$ 为命中建议数，最终分数封顶 100。

# 三、推荐对象适配分

$$S_{object} = \left(W_{rank} \times 0.30 + W_{subject} \times 0.25 + W_{stage} \times 0.20 + W_{time} \times 0.15 + W_{difficulty} \times 0.10\right) \times 100$$

| 参数 | 含义 | 取值规则 |
| :--- | :--- | :--- |
| $$W_{rank}$$ | 学习建议配置顺序 | 第 1 位取 1，第 2 位取 0.9，第 3 位取 0.8，依次递减，最低 0.5；非配置召回取 0.4 |
| $$W_{subject}$$ | 学科匹配 | 完全匹配取 1，全科覆盖取 0.8，不匹配取 0 |
| $$W_{stage}$$ | 学段/年级匹配 | 学段和年级均匹配取 1，只匹配学段取 0.7，不匹配取 0 |
| $$W_{time}$$ | 时间窗口匹配 | 当前处于计划可推荐窗口或时间节点匹配取 1；备考计划开始前 14 天内取 0.8；否则取 0.4 |
| $$W_{difficulty}$$ | 难度匹配 | 与掌握度分层匹配取 1；相邻难度取 0.7；不匹配取 0.3 |

# 四、原 5 条规则综合分

$$S_{origin} = \frac{\sum_{i=1}^{5}(S_{rule-i} \times W_{rule-i} \times W_{scene-i})}{\sum_{i=1}^{5}(W_{rule-i} \times W_{scene-i})}$$

说明：分母用于归一化，避免规则权重和场景调节系数相乘后导致原规则综合分满分低于 100。

| 规则 | 默认权重 | 含义 |
| :--- | :--- | :--- |
| 规则1 | 0.35 | 时间节点推荐 |
| 规则2 | 0.25 | 高关联学情应用优先 |
| 规则3 | 0.20 | 薄弱学科分级推荐 |
| 规则4 | 0.15 | 核心自研学情应用推荐 |
| 规则5 | 0.05 | 榜样用户推荐 |

## 场景调节系数

| 学情场景 | 规则优先级 | $$W_{scene}$$ |
| :--- | :--- | :--- |
| 常用自研学情/三方应用 | 规则1 > 规则2 > 规则3 > 规则4 > 规则5 | [0.35, 0.25, 0.20, 0.15, 0.05] |
| 常用自研非学情应用 | 规则2 > 规则1 > 规则3 > 规则4 > 规则5 | [0.25, 0.35, 0.20, 0.15, 0.05] |
| 偶尔使用学习机 | 规则5 > 规则1 > 规则2 > 规则3 > 规则4 | [0.20, 0.25, 0.15, 0.10, 0.30] |

# 五、学习建议到候选池的算法处理

| 建议类型 | 候选召回 | 对象类型倾向 |
| :--- | :--- | :--- |
| 知识掌握风险 1-3 | 同步精准学、同步学习、全科练习、所有学习计划 | 应用 55%，计划 45% |
| 正确率风险 4 | 错题本、阶段测、全科练习、精品密卷、所有学习计划 | 应用 60%，计划 40% |
| 单词复习 5 | AI 记单词、英语同步学习、词典、英语专项学习计划 | 应用 70%，计划 30% |
| 阅读/写作/背诵/字词 6-9 | 语文相关配置应用、语文专项学习计划 | 应用 70%，计划 30% |
| 学习计划落后 10 | 当前进行中的落后计划 | 计划 100% |
| 错题待订正 11 | 错题本、全科练习 | 应用 100% |
| 视频进度不足 12 | 当前视频所在应用、语文同步学习、AI 课本 | 应用 100% |
| 连续性风险 13-15 | 最近中断学科的基础应用或短周期计划 | 场景 3 计划优先，其余应用优先 |
| 方法/习惯 16-21 | 不独立召回，仅对练习类、错题类、计划类候选加权 | 排序修正 |
| 健康提醒 22-23 | 不进入学习应用/计划候选池 | 不推荐学习对象 |

对象类型倾向用于修正 $$S_{object}$$：候选对象类型符合倾向时，$$W_{rank}$$ 增加 0.1，封顶 1；不符合时不扣分。

# 六、可推荐校验

$$W_{valid}=1$$ 需要同时满足以下条件：

- 推荐对象适用学段覆盖用户学段。
- 推荐对象适用学科覆盖学习建议真实学科；学习建议为全科时，使用触发指标对应的真实学科。
- 推荐对象适用年级、机型、教材没有冲突。
- 学习计划处于可推荐时间窗口，或属于允许提前预热的备考计划。
- 用户未在抑制期内拒绝过该对象或同类建议。
- 对象未被禁用、下架或运营侧管控。

任一条件不满足时，$$W_{valid}=0$$。

# 七、反馈和疲劳权重

## 用户反馈权重

| 反馈 | $$W_{feedback}$$ |
| :--- | :--- |
| 家长查看且孩子使用有成效 | 1 |
| 家长查看但孩子未使用，或使用暂无成效 | 0.5 |
| 家长点击“暂不需要” | 0 |

多轮反馈叠加：

$$W_{feedback-final} = W_{latest} \times 0.7 + W_{history} \times 0.3$$

超过 60 天的历史反馈权重降至 20%。

## 曝光疲劳权重

| 场景 | $$W_{fatigue}$$ |
| :--- | :--- |
| 7 天内未曝光同对象 | 1 |
| 7 天内已曝光同对象 | 0 |
| 7 天内曝光过同一建议原因 | 0.5 |
| 指标较上次恶化超过 30% | 1 |
| 学习建议指标已改善 | 0.3 |

# 八、推荐间隔

$$Interval = BaseInterval \times (1 + \alpha D + \beta F + \gamma N - \delta U)$$

| 参数 | 含义 | 取值 |
| :--- | :--- | :--- |
| $$BaseInterval$$ | 基础间隔 | 冷启动 7 天；深度关注 3 天；中度关注 7 天；轻度关注 14 天；极少关注 30 天 |
| $$D$$ | 消化系数 | 完成率 < 30% 取 0.5；30%-80% 取 0.3；>= 80% 取 0 |
| $$F$$ | 反馈系数 | 未查看 0.5；查看未使用 0.3；查看且使用 0；不考虑 -0.2 |
| $$N$$ | 新鲜度系数 | 近 3 次重合度 >= 50% 取 0.3；新对象取 -0.2 |
| $$U$$ | 建议紧急系数 | 学习建议优先级 1-4 且持续恶化取 0.3；优先级 5-12 取 0.15；其余取 0 |

# 九、排序输出

最终输出时按以下顺序处理：

1. 按 $$S_{total}$$ 降序排序。
2. 同分时，学习建议直接配置对象优先。
3. 同分且均为直接配置对象时，按学习建议表中的配置顺序排序。
4. 同屏最多展示 1 个主推荐和 2 个备选推荐。
5. 推荐理由优先使用学习建议文案变量，其次使用原规则解释。
